# Input/output data dictionary

Exact private input snapshots and original source paths/SHA256: baseline_manifest.json. Raw matrix prices_valuation.csv is date × 32 tickers; source, series_type, currency, unit, adjustment convention and known publication limitations are recorded per ticker in input_dictionary.csv. prices_eligible.csv is the separate decision-information matrix. availability_ledger.csv records session_date, asset, observed_at, available_at, availability_basis and source. Modeled timestamps are not certified first-public releases. Original provider-record/publication history is incomplete; no value is invented. C1 is conditional on the accepted frozen proxy-availability contract; claims requiring verified PIT or actual execution stop here. C2 is stopped until its independent source pack exists.

Equities: KBS provider-native adjusted integer close /1000 (thousand VND/share), no additional cash dividend. GOLD: archived SJC-HCM selling close, thousand VND/luong, approximate source resolution 100000 VND; next-calendar-day eligibility. VFF: FMarket product 21, original NAV /1000, thousand VND/fund unit; five observed-session buffer plus later provider metadata. Check original raw identity hash in input_dictionary.csv. Dates/calendar inherited from frozen observed Vietnamese sessions; no new calendar invented.

selected_k5_events.csv (root export) adds effective_selection_date = first assumed execution using that selection_state_id. The immutable run export is retained without this later convenience column. rebalance_calendar.csv preserves all 310 decisions/fills, state IDs and initial/terminal dates. Membership history_end is strictly before decision_date.

C1_daily.csv: one row per strategy/date; continuous IS→OOS gross/net NAV, gross and cost-scenario daily return. First anchor return is empty. Re-anchor each phase at its recorded preceding valuation date for reported phase metrics; do not use full-period wealth as OOS NAV. Holdings: three *_holdings_weights.csv, weights at start of the indexed return. C1_units.csv stores post-close units; unit × valuation price plus cash reconstructs wealth.

C1_trades.csv: one row per asset × event × strategy (all 32 assets, including zero positions). pre_trade_weight, target_weight, weight_change are asset-specific. turnover, traded_notional and event_cost_fraction_* are EVENT-LEVEL values repeated on each asset row: deduplicate by strategy/execution_date before summing them. Full traded notional = sum absolute weight changes = 2 × one-way turnover, including cash deployment convention; initial deployment excluded from annual TO. Initial cost charged once IS; terminal event charged.

C1_results.csv: phase IS/OOS, 0/10/25/50 bps per traded side; ann_return/volatility/MDD are fractions, Sharpe and HHI dimensionless, turnover portfolio-equivalent one-way trades/year, final_nav starts at 1 per phase. N=906/641. mean_effective_holdings = mean(1/daily HHI) over positive-investment return days, not inverse of mean HHI. Target HHI applies at execution, daily HHI at start of return.

comparisons.csv includes all 16 phase × pair × cost combinations and 4 metrics each; CAGR/MDD differences are percentage points. paired_uncertainty.csv is gross OOS only, block10 noncircular paired returns, 1000 draws, seed20261104. No refitting. Raw prices and vendor histories excluded from upload; a licensed local input pack is necessary for a fresh simulation.

C1_event_trades.csv is a convenience export with one row per strategy/event (930 rows), so event turnover/notional/cost values can be summed there without the repeated-asset-row hazard.
